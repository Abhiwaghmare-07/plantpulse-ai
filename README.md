# PlantPulse AI - Predictive Maintenance System

PlantPulse AI is an intelligent, full-stack predictive maintenance platform designed to monitor industrial plant equipment in real time, detect anomalies, and forecast potential failures before they occur — minimising downtime and reducing operational costs. The system is built as a modern monorepo comprising a React-powered client dashboard, a Node.js/Express REST API backend, and a Python FastAPI microservice that serves machine-learning models trained on sensor telemetry data. A shared `data/` directory houses raw and processed datasets used during model training and evaluation.
